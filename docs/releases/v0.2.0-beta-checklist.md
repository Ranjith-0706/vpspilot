## 6. NSIS and MSI upgrade testing: Pending

## 7. Downgrade protection: configured, test pending

- [ ] With 0.2.0 installed, an older MSI refuses to install with an error.
- [ ] An older NSIS installer cannot be used in silent mode; interactive mode requires uninstalling first.
- [ ] User data is intact after the blocked attempt.

## 8. Uninstall and user-data preservation: Pending

- [ ] NSIS uninstall with "Delete the application data" **unchecked** keeps `%APPDATA%\com.vpspilot.desktop`.
- [ ] NSIS uninstall with it **checked** removes that folder.
- [ ] MSI uninstall: record whether user data is kept (not yet known).
- [ ] The uninstaller never touches anything outside the app and its own data folder.
- [ ] Reinstalling after an uninstall that kept data shows the old servers.

## 10. Real Linux VPS testing: Pending

Use a throwaway server. Follow `docs/testing/mvp-validation-report.md` Appendices A and B.

- [ ] Password login and unencrypted key login; wrong password and unreadable key errors.
- [ ] Host key prompt, trust, and a changed host key being refused.
- [ ] Terminal: input, resize, closing, behavior when the server is deleted while open.
- [ ] Monitoring: CPU, memory, disk, load, uptime on the server's distribution; stop, retry, reconnect after a network drop.
- [ ] History: samples recorded, charts load, retention cleanup after time passes.
- [ ] Alerts: fire, resolve, and "status unknown" during an outage.
- [ ] Docker: container list and logs with a permitted account; the permission error with an account that cannot run `docker`.
- [ ] 2 to 3 servers at once; each keeps its own status and history.
