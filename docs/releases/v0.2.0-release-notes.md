# VPSPilot v0.2.0 (beta): Release Notes (DRAFT)

**Draft. Not published.** Do not use until the release checklist is complete and the owner approves.

## What it is

VPSPilot is a standalone Windows desktop application for monitoring and managing Linux VPS servers through SSH. It runs on your PC. No cloud backend, AWS account or Linux agent is needed.

## Highlights

- Persistent monitoring history: CPU, memory, disk and load samples are stored locally (7 days by default, 1 to 90 in Settings), with a History tab on the Dashboard.
- One consistent connection status across the Dashboard and Servers pages.
- Compact, responsive interface with light and dark themes.
- Stability fixes for terminal sessions, session revocation, alerts and credential changes.
- Windows installers: NSIS setup (recommended) and MSI. Installing an older version over a newer one is blocked.

Earlier features: server profiles with credentials in the Windows Credential Manager, SSH connection test with host key verification, interactive SSH terminal, live monitoring, threshold alerts, read-only Docker container list and logs.

## Install

See the [Windows beta installation guide](../development/windows-beta-install.md). The installers are **unsigned**, so Windows SmartScreen shows a warning. Compare the SHA-256 checksum from the release manifest before running.

## Known limitations

- Unsigned installers.
- Not yet verified against real Linux servers or on a clean Windows PC (see the checklist for the current state).
- Password or unencrypted private key only; no passphrase keys, ssh-agent or jump hosts.
- Docker support is read-only. Monitoring runs only while the app is open.
- Windows only; monitoring and Docker need a Linux server.
